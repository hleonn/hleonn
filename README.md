## 🚀 Featured Project — Live Now

### [AI Learning Graph Intelligence Platform](https://ai-learning-graph.vercel.app/)
> *Feb 2026 – Present*

A full-stack platform that models student knowledge as a **graph** and uses LLMs to detect learning gaps and generate personalised learning paths. Built to address real challenges in curriculum design, learning analytics at scale, and AI-powered content generation.

```
Graph Engine ──▶ Supabase ──▶ Next.js / TypeScript ──▶ Claude API / DeepSeek API
                                     │
                              Google Cloud OAuth
                                     │
                          Flutter mobile client (Phase 2+)
```

**Key capabilities:**
- 🧠 Knowledge graph modeling with prerequisite-aware content sequencing
- 📊 Learning gap detection across student cohorts
- ✍️ Auto-generation of learning paths from teacher input
- 🔐 Secure auth via Google Cloud OAuth + Supabase

`Next.js` `TypeScript` `Supabase` `PostgreSQL` `Claude API` `DeepSeek API` `Graph Engine` `Flutter`
