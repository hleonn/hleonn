### [AI Learning Graph Intelligence Platform](https://ai-learning-graph.vercel.app/)
`Feb 2026 – Present` · Full-stack · AI-powered · In production

A platform that models student knowledge as a **knowledge graph** and uses LLMs (Claude API, DeepSeek) to detect learning gaps and generate personalised learning paths automatically.

**What it does:**
- 🧠 Maps prerequisites between learning objectives as a directed graph
- 📊 Detects knowledge gaps across student cohorts at scale
- ✍️ Auto-generates curriculum sequences from teacher input using AI
- 🔐 Google Cloud OAuth + Supabase for secure multi-tenant auth
- 📱 Flutter mobile client planned for Phase 2

</td>
