## What I'm building now

### [AI Learning Graph Intelligence Platform](https://ai-learning-graph.vercel.app/) `2026 – present`
> Full-stack platform that models student knowledge as a **directed graph** and uses LLMs (Claude API, DeepSeek) to detect learning gaps and generate personalised paths.

**Why it's non-trivial:**
- Knowledge prerequisites modelled as a DAG — not a flat curriculum
- Real-time gap detection across student cohorts
- AI-generated learning paths from teacher-defined objectives
- Google Cloud OAuth + Supabase Gateway + Graph Engine integration
- Flutter mobile client in Phase 2

`Next.js` `TypeScript` `Supabase` `Claude API` `DeepSeek API` `Google Cloud OAuth` `Graph Engine`
